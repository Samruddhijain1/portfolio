Melanoma Skin Cancer Detection

Problem: Early detection of melanoma is critical for patient outcomes. Traditional manual analysis is time-consuming and prone to human error.

Solution: Developed a medical image analysis system using Otsu's thresholding and morphological operations for accurate lesion segmentation from dermoscopic images.

Key Features:

  • Extracted ABCD features (Asymmetry, Border, Color, Diameter)
  • Achieved ~90% detection accuracy on ISIC dataset
  • Low computational complexity for real-time processing
  • Validated against annotated medical images

Technologies Used:

MATLAB, Image Processing Toolbox, Medical Imaging Principles

SimpLearn Compiler

Objective: Create an educational compiler prototype that demonstrates fundamental compiler design concepts and phases.

Implementation: Designed a basic compiler supporting a simplified programming language with essential control flow and data structures.

Supported Features:

  • Variable declarations and assignments
  • Conditional statements (if-else)
  • Loop constructs (for, while)
  • Lexical analysis (tokenization)
  • Syntax parsing and abstract syntax trees
  • Simple code generation

Learning Outcomes:

Deep understanding of compiler architecture, parsing techniques, and language design principles.

Inventory Management Optimization System

Challenge: Organizations struggle with inventory decisions - balancing stock levels while minimizing costs and stockouts.

Solution: Developed an Operations Research-based system implementing multiple inventory optimization models with an interactive interface for decision-making.

Implemented Models:

  • Economic Order Quantity (EOQ): Determines optimal order size
  • Reorder Point (ROP): Identifies when to place new orders
  • Safety Stock: Buffer inventory to prevent stockouts
  • Bulk Discount Models: Optimizes pricing strategies

Key Features:

  • Interactive Streamlit web application
  • Custom Python library for calculations
  • Visual optimization strategy analysis
  • Cost minimization insights

Technologies:

Python, Streamlit, NumPy, Matplotlib, Operations Research
